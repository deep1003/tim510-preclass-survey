# TIM51001 Pre-Class Research Interest Survey

Static GitHub Pages survey for TIM51001 Business Analytics.

The page is designed for pre-class diagnosis of students' research interests, data interests, and prior analysis experience.

## Response storage

The page opens a prefilled GitHub Issue when students click the save button.

Students must submit the prefilled issue on GitHub. Responses are then collected in the repository Issues list under the `survey-response` label.
